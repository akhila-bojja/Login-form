# 🔐 Login Form

This is a beginner-friendly Login Form project built using HTML, CSS, and JavaScript. It includes basic email/password input validation and a simple alert-based login simulation.



## 🚀 Live Demo

👉 [Click to View the Live Demo](https://akhila-bojja.github.io/Login-form/)


## 📁 Project Structure

Login-form/
│
├── index.html # Main HTML structure
├── style.css # Styling for the form and layout
└── script.js # Basic JavaScript validation



✨ Features

- Clean and simple login form UI
- Basic validation using JavaScript
- Displays error for incorrect credentials
- Easy to understand and modify

## 🧠 What I Learned

- How to structure HTML forms
- Applying CSS styles using flexbox and spacing
- JavaScript DOM manipulation and form handling
- Preventing default form actions and using alert/error messages

## 🛠 Technologies Used

- HTML5
- CSS3
- JavaScript
